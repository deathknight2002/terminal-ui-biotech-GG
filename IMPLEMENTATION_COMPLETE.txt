                       KEY FEATURES

Backend:

  - Interactive timeline scrubber
  - Manual REFRESH button (NO auto-updates)
  - Color-coded nodes (thesis=purple, trial=blue, catalyst=orange)
  - Click nodes for details or timeline

Architecture:
  - Manual refresh only - NO real-time features
  - Standard HTTP fetch (no WebSockets)
  - User-initiated data loading
  - Works offline with cached data

═══════════════════════════════════════════════════════════════════════
                       PRODUCTION DEPLOYMENT
═══════════════════════════════════════════════════════════════════════

Steps to deploy:

1. Update CORS in standalone_evidence_api.py:
   allow_origins=["https://yourdomain.com"]

2. Set environment variables:
   VITE_PYTHON_API_URL=https://api.yourdomain.com

3. Deploy Python FastAPI backend (port 8000)

4. Build and deploy React frontend:
   cd terminal && npm run build

5. Configure reverse proxy (nginx/caddy) if needed

6. Done! ✨
