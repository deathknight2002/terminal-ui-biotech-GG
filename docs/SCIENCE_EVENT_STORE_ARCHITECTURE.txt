DATA FLOW EXAMPLES
==================

1. CREATE EVENT:
   Client → TypeScript API → FastAPI POST /science-events → Pydantic Validation
   → SQLAlchemy ORM → INSERT INTO science_events → Return ID + metadata

2. QUERY TIMELINE:
   Client → GET /timeline/DRUG/BPX-IL23 → Filter by entity_type + entity_id
   → ORDER BY event_date → Return chronological events

3. UPDATE EVENT (Versioning):
   Client → PUT /science-events/123 → Mark v1 as is_current=false
   → INSERT new row with version=2, parent_version_id=123 → Return new ID

4. SEARCH:
   Client → GET /search?q="IL-23 inhibitor" → ILIKE on title/description/content
   → Return matching events with highlights
