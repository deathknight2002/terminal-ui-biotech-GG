## Badge Legend

### Importance Badges
- 🚨 **CRITICAL** - Major FDA approvals, breakthrough trial results, M&A
- ⚠️ **HIGH** - Positive clinical data, significant partnerships
- **MEDIUM** - Pipeline updates, early-stage results
- **LOW** - Routine corporate updates

### Feature Badges
- 📊 **TRADABLE** - SMID-cap catalyst event (high volatility potential)
- ⭐ **PORTFOLIO** - Relevant to watchlist companies
- **Small Cap** / **Mid Cap** / **Micro Cap** - Market capitalization

### Category Badges
- **Trial Results** - Clinical trial data readouts
- **FDA Approval** - Regulatory approvals
- **Partnership** - Collaboration announcements
- **M&A** - Mergers and acquisitions
- **Financing** - Funding rounds, offerings

## Filter Interactions

### 1. Category Filter
```
Click: [🧬 SMA (3)]
Result: Shows only 3 SMA-related articles
```

### 2. Tradable Filter
```
Click: [📊 TRADABLE ONLY]
Result: Filters to show only SMID-cap catalyst events
- ✅ Scholar Rock (Small Cap, Phase 3 results)
- ✅ Crinetics (Mid Cap, Phase 2 data)
- ❌ Novo Nordisk (Mega Cap, too large)
```

### 3. Portfolio Filter
```
Click: [⭐ PORTFOLIO ONLY]
Result: Shows only watchlist-relevant news
Watchlist: SRRK, CRNX, IONS, VRTX, BIIB
```

### 4. Search
```
Type: "phase iii"
Result: Shows articles mentioning Phase III trials
- Scholar Rock SAPPHIRE trial
- Other Phase 3 programs
```

### 5. Combined Filters
```
Select: [🔬 RARE DISEASE] + [📊 TRADABLE ONLY]
Result: SMID-cap rare disease catalysts only
- Scholar Rock (SMA)
- Crinetics (Acromegaly)
```

## Ranking Logic

Articles are automatically ranked by:

1. **Importance** (Critical > High > Medium > Low)
2. **Portfolio Relevance** (Watchlist first)
3. **Relevance Score** (0-100, based on keywords)
4. **Recency** (Newest first within same importance)

Example Order:
```
1. [🚨 CRITICAL] [⭐ PORTFOLIO] Scholar Rock - Score: 95
2. [⚠️ HIGH] [⭐ PORTFOLIO] Crinetics - Score: 88
3. [⚠️ HIGH] Novo Nordisk - Score: 75
4. [MEDIUM] [⭐ PORTFOLIO] Ionis - Score: 82
5. [MEDIUM] Small Biotech - Score: 72
```

## API Integration

The UI connects to:
```

  ?maxResults=100
  &category=SMA
  &tradable=true
  &watchlist=SRRK,CRNX,IONS

Response: {
  success: true,
  count: 45,
  articles: [...],
  categoryCounts: {
    all: 45,
    SMA: 3,
    ...
  }
}
```
